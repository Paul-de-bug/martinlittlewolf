# Martin Littlewolf Website

Static website for [martinlittlewolf.com](https://www.martinlittlewolf.com/).

The site uses plain HTML, JavaScript, and CSS. It has no package manager,
framework, or build step. Edit the files directly and preview them with any
local static web server.

## Important files

- `index.html` — homepage
- `styles/site.css` — shared site styling
- `assets/` — images, downloadable PDFs, and solution-image collections
- `solutions-*.html` — interactive solution viewers
- `CNAME` — GitHub Pages custom-domain configuration

The compiled stylesheet is intentionally committed because GitHub Pages serves
the repository as a static site.
